[새 기능]
- 다크 테마로 디자인을 새로 만들고 창 크기를 크게 줄였어요 (340 × 212)
- 탭 정리: 녹화 / 오디오 / 단축키 / 설정
- 설정 탭 추가: 녹화 방식(게임 호환 / 기본), 프레임(60 / 30 fps), 화질(높음 / 보통 / 낮음)
- '게임 호환' 녹화 방식 추가: 전체 화면 게임도 녹화돼요 (기본값)
- 게임 실행 중에도 녹화 단축키가 동작해요
- 오디오 미터를 dB 눈금으로 바꿨어요 (빨간색은 실제로 소리가 찢어질 때만 켜져요)
- 트레이 아이콘과 메뉴 추가 (녹화 시작/중지, 영역 지정, 폴더 열기, 종료)
- 녹화가 끝나면 마지막 파일 이름을 보여 주고, [폴더]를 누르면 그 파일을 선택해서 열어요
- 영역 지정 화면에 크기가 표시되고, 녹화 중에는 테두리가 빨간색으로 바뀌어요
- 창 제목 표시줄에 버전이 표시돼요
[버그 수정]
- 마이크 소리가 너무 작게 녹음되던 문제
- 마이크 음량 슬라이더 값이 튀던 문제
- 마이크 미터가 선택한 마이크가 아닌 기본 마이크를 보여 주던 문제
- 마이크 녹음을 꺼도 Windows 마이크 사용 표시가 계속 켜져 있던 문제
- 녹화를 멈춘 직후 파일 저장이 끝나기 전에 새 녹화가 시작될 수 있던 문제
- 녹화 중에 종료하면 녹화 파일이 깨질 수 있던 문제 (이제 저장이 끝난 뒤 종료)
- 오래 녹화하면 메모리가 계속 늘어나던 문제
- 스피커/헤드폰을 바꾸면 미터가 멈추던 문제
- 영역을 화면 밖으로 끌면 녹화가 실패하던 문제
- 단축키를 누르고 있으면 녹화 시작/중지가 반복되던 문제
- 단축키 입력칸에서 키를 누르면 녹화가 시작되던 문제
- 다른 프로그램이 이미 쓰는 단축키로 등록에 실패해도 알려 주지 않던 문제
- 폴더 경로에 공백이 있으면 녹화 폴더가 제대로 열리지 않던 문제
- 업데이트 임시 파일 이름이 다른 프로그램과 겹치던 문제
