- 레이아웃 디자이너: 디자이너 시작 시 '최근 작업한 레이아웃' 추가

===== [ 이전 업데이트 내역 ] ====

- 업데이트 확인 창에 업데이트 내역 표시 (최신 버전이면 지금 버전 내역, 새 버전이 있으면 새 내역)
- 테마 바꾸기 버튼 추가 (어두운 테마 / 밝은 테마)
- 레이아웃 디자이너: 효과음 (게임을 넘길 때 / 실행할 때 / 디스플레이를 바꿀 때 / 레이아웃이 열릴 때)
- 레이아웃 디자이너: 화면 효과 (흑백, 세피아, 흐리게, CRT 주사선, 가장자리 어둡게)
- 레이아웃 디자이너: 화면 전체 효과 (가장자리 어둡게, CRT 주사선)
- 레이아웃 디자이너: 템플릿으로 저장 / 새로 만들기에서 템플릿 고르기
- 레이아웃 디자이너: [미리보기 디스플레이 선택] - 디스플레이로도 미리보기 게임을 고를 수 있음
- 레이아웃 디자이너: 상태 줄에 미리보기 게임 · cfg · system 이름 표시
- 레이아웃 디자이너: 기종 그림 고르기가 지정한 기종별 이미지 폴더에서 열림 (폴더가 없으면 폴더 선택)
- 레이아웃 디자이너: 숫자 옵션 · 직접 입력 옵션을 속성에 그대로 연결 (휠 개수, 투명도, 움직임 속도 등)
- 밝은 테마에서도 디자이너 편집 화면은 어둡게 유지
- 미리보기 게임 목록에 다른 에뮬레이터 게임이 섞여 나오던 문제 수정
- 업데이트할 때 설치 진행 창(cmd)이 보이도록 변경, 한글이 겹쳐 보이던 문제 수정
- 레이아웃 디자이너: 레이아웃 옵션 (어트랙트모드 레이아웃 설정 화면에 나오는 선택 항목)
- 레이아웃 디자이너: 옵션 값에 따라 보이기/숨기기, 옵션 값별 속성 바꾸기
- 레이아웃 디자이너: 휠 오브젝트 추가
- 레이아웃 디자이너: 그룹으로 묶기 / 풀기 / 그룹에서 하나만 빼기, 오브젝트 이름 바꾸기 (F2)
- 레이아웃 디자이너: 기종 이미지 (에뮬레이터 cfg 의 system 이름으로 기종 그림 표시)
- 레이아웃 디자이너: 목록 가로 스크롤, 흘러가는 배경의 이음새 수정, 글자 위아래 맞춤 보정
- 레이아웃 디자이너 사용 설명서 작성
- 화면 전체를 새로 디자인 (어두운 테마, 왼쪽 메뉴: 게임 관리 / 레이아웃 디자이너)
- 레이아웃 디자이너 새로 만듦: 화면을 보면서 이미지·영상·아트워크·텍스트·게임 목록을 배치하고 움직임을 정해 layout.nut 으로 저장
- 롬리스트 관리, 미디어 감사, 필터 테스터 화면 제거
- 프로그램 이름을 Attractmode Manager Pro 로 변경
